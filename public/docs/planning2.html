업보의 메아리 (Echo of Karma)

개발 기획서 v2.0 — 2026.04.11 업데이트

1. 게임 개요

포스트 아포칼립스 세계에서 기억을 잃은 주인공이 정착지에서 살아남으며 과거와 마주하는 내러티브 RPG. 선택에 따라 자원이 변하고, 랜덤 이벤트가 발생하며, 6가지 엔딩으로 분기된다.

  • 플랫폼: 웹앱 (모바일 퍼스트) + APK (Capacitor)
  • 1회 플레이 시간: 10~15분
  • 리플레이: 랜덤 이벤트 + 분기 선택지 + 6개 엔딩 수집
  • 기술 스택: React 18 + TypeScript + Vite + Zustand

2. 핵심 시스템

2-1. 자원 관리 NEW

자원아이콘초기값범위역할
체력(HP)❤50~8전투/위험 선택의 대가. 0이면 게임오버
식량🍞50~83턴마다 1 소모. 0이면 매 턴 HP -1
신뢰도🤝30~6NPC 관계. 특정 선택지 잠금 해제
  • 선택지마다 자원 비용이 표시됨
  • 식량 0 이후: 매 턴 HP -1 (굶주림)
  • 신뢰도 부족 시 일부 선택지 잠금 (루카 협상, 칸 대화 등)
  • HP 0 = "쓰러진 자" 게임오버 엔딩

2-2. 카르마 시스템

  • 범위: 0~12 (초기값 5)
  • 선택지에 따라 증감, 실시간 게이지 표시
  • 엔딩 조건의 핵심 변수
  • 카르마 ≤4: 속죄 엔딩 가능 / 카르마 ≥9: 폐허의 왕 엔딩

2-3. NPC 생존 추적

NPC역할생존 조건
정 노인정착지 지도자분기점 B에서 결정
이설플레이어의 도덕적 거울카르마 ≤6 또는 특정 대화
민준어린 아이, 죄책감 상징분기점 A에서 결정
루카숨겨진 동맹턴 9에서 발견 시 등장

3. 스토리 구조

3-1. 3막 20턴 구조

막턴핵심 이벤트
1막: 도입1~7세계 인식, 분기점 A (민준의 선택)
2막: 갈등8~14갈등 심화, 루카 발견, 분기점 B (장로의 결단)
3막: 클라이맥스15~20최종 대결, 분기점 C (칸과의 대면)

3-2. 선택지 반응 시스템 NEW

  • 선택 직후 responseText로 즉각적인 결과 피드백
  • 예: "경계하며 일어선다" → "주먹을 쥐고 몸을 일으킨다. 다가오던 그림자가 잠시 멈칫한다."
  • 이전 선택에 따라 다음 씬의 대사가 분기됨
  • 예: 턴 1에서 경계 → 턴 2 이설이 "경계심이 강하시군요..." / 관찰 → "이틀이나 의식이 없었거든요"

3-3. 랜덤 이벤트 시스템 NEW

턴 3~18 사이에 35% 확률로 랜덤 이벤트 발생. 같은 플레이에서도 다른 경험을 제공.
